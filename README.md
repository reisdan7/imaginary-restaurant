# Imaginary Restaurant

A landing page for a fictional restaurant, built with only HTML and CSS. No JavaScript, no frameworks.

**This project was made to practice HTML and CSS.** I built it to get more comfortable with layouts, responsive design and styling, and to have something real to show in my portfolio.

**Live demo:** https://reisdan7.github.io/imaginary-restaurant

## What's on the page

- Fixed navigation bar with a hamburger menu on mobile (built with a checkbox, no JS)
- Hero section with a call to action
- Restaurant numbers, our story and a menu with 6 dishes
- Photo gallery in a grid, guest reviews and a reservation form
- Responsive layout for desktop, tablet and mobile

## What I practiced

- Flexbox and Grid
- Media queries
- Transitions and hover effects
- Positioning with `fixed` and `absolute`
- CSS variables
- Semantic HTML

## How to run

Download the project and open `index.html` in your browser.

```bash
git clone https://github.com/reisdan7/imaginary-restaurant.git
cd imaginary-restaurant
```
